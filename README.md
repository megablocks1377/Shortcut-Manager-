# Shortcut Manager

Shortcut Manager is a productivity application that helps users quickly find, organize, and customize keyboard shortcuts across multiple software applications.

The application detects currently open programs, identifies the software being used, and provides a list of relevant shortcuts for that application. It also allows users to create custom shortcuts that can be reused across multiple applications.

---

## Overview

Many applications use different keyboard shortcuts, making it difficult to remember commands when switching between programs.

Shortcut Manager solves this problem by providing a centralized shortcut reference that adapts to the applications currently being used.

For example, when Google Chrome is open, Shortcut Manager can display Chrome-specific shortcuts. When another application is detected, the shortcut list can update to show commands relevant to that software.

Users can also define general shortcuts for actions that are common across multiple applications, such as:

- `Ctrl + C` — Copy
- `Ctrl + V` — Paste
- `Ctrl + Z` — Undo
- `Ctrl + S` — Save

---

## Features

- Detects currently open applications
- Identifies shortcuts associated with detected software
- Displays application-specific shortcut references
- Allows users to create custom shortcuts
- Supports shortcuts that can apply across multiple applications
- Organizes shortcut information in one centralized interface
- Helps reduce the need to memorize software-specific commands

---

## How It Works

1. Shortcut Manager scans the applications currently running on the computer.
2. The application identifies supported software.
3. Relevant shortcuts are retrieved and displayed to the user.
4. Users can browse shortcuts for individual applications.
5. Users can create custom shortcuts and associate them with one or multiple applications.
6. General shortcuts can be stored for actions commonly shared across software.
